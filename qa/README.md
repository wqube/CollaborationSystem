# QA Artifacts

Ветка `QA` содержит актуальные QA-артефакты по проекту **CollaborationSystem**.

## Структура

- `deadline-1/`
  - исходные артефакты первого дедлайна: тест-план, smoke checklist, API-описание, Postman collection и шаблон баг-репортов
- `deadline-2/`
  - результаты smoke/UI тестирования
  - подтвержденные баг-репорты
  - ревью дизайна
  - API-артефакты:
    - `api-auth/`
    - `api-non-auth/`
- `deadline-3/`
  - итоговые QA-артефакты
  - регрессионный отчет
  - отчет по ретесту исправлений
  - актуализированные тест-кейсы
  - полная QA-документация
  - презентация для защиты

## Финальный актуальный комплект

Если нужен именно последний актуальный пакет документов, в первую очередь смотреть:

- `deadline-3/Полная_QA_документация_CollaborationSystem.docx`
- `deadline-3/Итоговый_отчет_о_тестировании.docx`
- `deadline-3/Отчет_API_регрессия.docx`
- `deadline-3/Отчет_по_ретесту_исправлений.docx`
- `deadline-3/ТЕСТ-КЕЙСЫ_актуализированные_релиз2.docx`
- `deadline-3/Защита_QA_CollaborationSystem.pptx`
