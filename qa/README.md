# QA Artifacts

Ветка `QA` содержит актуальные QA-артефакты по проекту **CollaborationSystem** в финальной, упрощённой структуре.

## Структура каталога `qa/`

### Основные документы

- `ТЕСТ-ПЛАН.docx` — тест-план проекта
- `ТЕСТ-КЕЙСЫ_актуализированные_релиз2.docx` — актуализированные тест-кейсы
- `Smoke_checklist_текущий_статус.docx` — актуальный smoke checklist
- `Баг-репорты_подтвержденные.docx` — подтверждённые дефекты
- `Документация_по_автотестам_CollaborationSystem.docx` — отдельная документация по добавленным автотестам
- `Итоговый_отчет_о_тестировании.docx` — итоговый отчёт о тестировании
- `Полная_QA_документация_CollaborationSystem.docx` — сводный комплект QA-документации

### API

Папка `API/` содержит артефакты по API-тестированию:

- `API/api-auth/`
  - `CollaborationSystem Auth.postman_collection.json`
  - `Отчет_API_auth.docx`
- `API/api-non-auth/`
  - `CollaborationSystem Non-Auth API.postman_collection.json`
  - `Отчет_API_non_auth.docx`
- `API/Отчет_API_регрессия.docx`

## Какие файлы считать основными

Если нужен именно актуальный финальный пакет для проверки или защиты, в первую очередь смотреть:

- `Полная_QA_документация_CollaborationSystem.docx`
- `Итоговый_отчет_о_тестировании.docx`
- `ТЕСТ-КЕЙСЫ_актуализированные_релиз2.docx`
- `Smoke_checklist_текущий_статус.docx`
- `Баг-репорты_подтвержденные.docx`
- `Документация_по_автотестам_CollaborationSystem.docx`

## Дополнительно

- QA-артефакты вынесены в отдельную ветку для удобного просмотра на GitHub.
- Временные системные и офисные файлы (`.DS_Store`, `~$...`) в состав артефактов не входят.
