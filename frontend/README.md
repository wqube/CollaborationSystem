# Collaboration System Frontend

Frontend-часть системы совместной работы над предложениями по улучшению
процессов разработки.

Приложение позволяет пользователям работать с проектами, создавать предложения,
голосовать за и против них, обсуждать предложения в комментариях, сохранять
черновики и управлять настройками проекта в роли администратора.

## Стек

- React
- TypeScript
- Vite
- React Router DOM
- Redux Toolkit
- Axios
- CSS Modules
- ESLint

## Запуск

Из папки `frontend`:

```bash
npm install
npm run dev
```

По умолчанию frontend доступен на `http://localhost:5173`.

Для полноценной работы нужен backend API на `http://localhost:5227/api/v1`.
Самый простой способ поднять весь dev-стенд из корня репозитория:

```bash
docker compose -f docker-compose.dev.yml up --build
```

## Возможности

- Авторизация через dev-login с access token и refresh cookie.
- Автоматическое обновление access token через Axios interceptor.
- Список проектов пользователя.
- Создание нового проекта.
- Открытие последнего доступного проекта при входе через smart redirect.
- Список предложений проекта по статусам: новые, в работе, принятые,
  отклонённые.
- Отдельная вкладка черновиков предложений.
- Поиск, сортировка и пагинация предложений.
- Создание предложения с autosave-черновиком.
- Голосование за и против предложения из списка и детальной страницы.
- Отмена собственного голоса.
- Отображение лимита голосов и даты следующего сброса.
- Детальная страница предложения.
- Редактирование текста предложения автором.
- Изменение статуса предложения администратором проекта.
- Комментарии в древовидном виде с ответами.
- Черновики комментариев с autosave.
- Редактирование и удаление своих комментариев.
- Управление участниками проекта для администратора.
- Изменение ролей участников для администратора.
- Настройки проекта: название, описание, лимит голосов, период сброса.
- Удаление проекта администратором.

## Маршруты

| Маршрут | Назначение |
| --- | --- |
| `/login` | Страница входа |

## API

Базовый URL API задаётся в `src/shared/api/client.ts`:

```ts
baseURL: 'http://localhost:5227/api/v1'
```

Основные API-модули:

- `shared/api/auth.ts` — login, refresh, logout.
- `shared/api/project.ts` — проекты и настройки проекта.
- `shared/api/dashboard.ts` — дашборд проекта.
- `shared/api/suggestions.ts` — предложения и голосование.
- `shared/api/comments.ts` — комментарии.
- `shared/api/drafts.ts` — черновики.
- `shared/api/users.ts` — список пользователей для добавления в проект.

## Роли

- `Member` — создаёт предложения, голосует, комментирует, редактирует свои
  предложения и комментарии.
- `Admin` — имеет права `Member`, а также управляет настройками проекта,
  участниками, ролями и статусами предложений.

## Текущие ограничения

- Авторизация реализована как dev-login, без корпоративного SSO.
- Список пользователей берётся из backend API, который в MVP использует
  локальное хранилище пользователей.
- Jira-связи и расписание встреч/Outlook на frontend не реализованы, так как
  для них пока нет backend-контракта.
- На детальной странице редактируются только поля, которые поддерживает API:
  текст предложения, статус предложения и собственные комментарии.
